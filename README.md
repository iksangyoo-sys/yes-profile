AI Literacy 연구원입니다. AI 시대에 사람에게 더 필요하고 중요해진 분석력, 논리력, 표현력을 다루는 곳입니다.

`report/index.html`은 [koreport-skill](https://github.com/iksangyoo-sys/koreport-skill)의 `assets/sentence-patterns.html`(보고서 문장 공식)을 복사한 것입니다. 그쪽을 고치면 이 파일도 다시 복사합니다.

`hanja/index.html`은 보고서 한자 사용법입니다. 사내 「한자 사용 규칙」 정리표(엑셀)의 다섯 가지 쓰임(문장 줄이기, 문장 끝맺기, 뜻 분명히 하기, 키워드 강조, 사자성어)과 사례를 찾아보고 눌러서 복사할 수 있게 만든 한 장짜리 페이지입니다. 데이터는 페이지 안에 들어 있습니다.

`framework/index.html`은 기획 프레임워크 지도입니다. 업무분야별 기획의 끈 정리표(엑셀 「기획끈」)에 표준 프레임을 보완해 기획 목적 15가지와 업무 분야 10가지로 찾아보게 만든 한 장짜리 페이지입니다. 프레임마다 단계별 설명과 제조업 사례(버튼으로 펼침)를 담았고, 데이터는 페이지 안에 들어 있습니다.

`hub/index.html`은 AI리터러시연구원 자료 모음입니다. 「프롬프트·보고서 엔지니어링」(5개)과 「데이터사이언스」(5개, 그중 2개는 준비 중) 두 큰 원에 자료 원이 가지처럼 달린 마인드맵이고, 원 아래에 짧은 설명이 있습니다. 원을 누르면 해당 페이지가 새 창으로 열리고, 맨 위 인사말은 연구원 소개로 연결됩니다. 좁은 화면에서는 세로 목록으로 바뀝니다. 항목과 위치는 파일 안의 `HUBS`에서 고칩니다.
